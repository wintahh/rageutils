# RageUtils v1.0
Quality of Life mod for RageMines

This is a Fabric mod made natively for 1.21.11 and 1.21.8. 

Requirements : 
- `Fabric API`

If the version you want to use isn't in Releases, change these variables in `gradle.properties` according to https://fabricmc.net/develop:
- `minecraft_version`
- `yarn_mappings`
- `loader_version`
- `loom_version`
- `fabric_api_version`
  And change `depends/minecraft` in `src/main/resources/fabric.mod.json`
